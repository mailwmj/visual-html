# Shared PPT Output Contract

本文件定义 Generate PPT 和 Extend Style Pack 共同使用的 PPT HTML 舞台、交互、打印与验收契约。它是共享支持文档，不是顶层 route authority。

## 舞台与版面

- 画布固定为 16:9，推荐设计坐标为 `1280×720`。
- 每页只保留一个核心论点；不得使用长文滚动布局模拟幻灯片。
- 内容安全区距离四边保持约 5–7%，装饰可以越出安全区，但正文、关键数字、图例和来源不得越界。
- 页面按独立 `.slide` 断开。标题、图表、页码、来源和动态内容不得引发布局尺寸漂移。
- 正文溢出时拆页或重新组织内容，不使用不可读的小字号、裁切或隐藏溢出来掩盖问题。

## 演示交互

- 支持 `ArrowLeft` 返回上一页。
- 支持 `ArrowRight` 和 `Space` 前往下一页；在表单控件或可编辑元素中不得劫持空格。
- 支持 `F` 进入或退出全屏；全屏 API 不可用时保持基本翻页能力。
- 首尾页导航不得越界。当前页状态变化不应修改页面几何尺寸。

## 打印与导出

至少提供等价于以下行为的打印规则：

```css
@page { size: 16/9 landscape; margin: 0; }

@media print {
  body { padding: 0; background: none; }
  .slide {
    width: 100vw;
    height: 100vh;
    break-after: page;
  }
}
```

- 打印时移除演示控制、浏览器背景和页面间隙。
- 每页必须独立输出，不跨页截断内容。
- 在线字体、脚本或图表增强不可成为打印和离线阅读的必要条件。

## 视觉与行为验收

- [ ] 代表页在 16:9 视口中无文字溢出、遮挡、裁切或不可读缩放。
- [ ] 封面、正文、数据、比较等页型保持同一 Core Visual DNA。
- [ ] `ArrowLeft`、`ArrowRight`、`Space` 和 `F` 行为可用，首尾页不越界。
- [ ] 打印预览为无边距横向 16:9，每张幻灯片独立成页。
- [ ] 缺少在线资源时仍能阅读核心内容、图表和来源。
