# Generate PPT Route

本文件只在顶层 route 已确定为 **Generate PPT** 时读取。通用意图分析、风格选择和语义组件规则仍由 [`SKILL.md`](../../SKILL.md) 负责。

## 前置条件

- 已有长文本或可转换为演示结构的用户内容。
- 输出媒介已确定为 16:9 PPT；若同时要求 Web 和 PPT，先询问一个媒介区分问题。
- 风格已明确时锁定一个 `style_id`；风格未明确时，先运行现有风格选择 stage，再读取目标风格文件。用户也可以明确选择自由设计或参考图逆向。

## 加载集合

1. 读取目标风格的 `design.md`。
2. 读取目标风格的 `scaffold-ppt.html`。
3. 需要共享 DOM 语义时读取 [`shared-components.md`](../shared-components.md)。

不要读取目标 Web 脚手架或其他风格的设计规范，除非用户另有明确要求。若内容包含 Mermaid，仍按 `SKILL.md` 的共享离线 fallback 契约触发对应 bundler。

## 生成契约

- 使用 16:9 舞台和目标风格的视觉骨架；单页只保留一个核心论点。
- 可以压缩版面，但必须保留结论、关键指标和出处；被压缩的细节放入附录、备注或详细页。
- 画布固定为 16:9（如 `1280×720`），外层舞台预留 5–7% 安全边距；幻灯片按页断开，不使用长文滚动布局。
- 输出应包含演示翻页和打印导出的必要结构：支持 `←` / `→` / `Space` 翻页、`F` 进入/退出全屏，并提供无边距横向 16:9 打印规则。
- 打印样式至少满足：`@page { size: 16/9 landscape; margin: 0; }`、`body { padding: 0; background: none; }`、`.slide { break-after: page; width: 100vw; height: 100vh; }`。
- 生成完成后按 [`SKILL.md`](../../SKILL.md) 的通用质量清单和目标风格专属清单验收。

## 完成条件

只有在所有幻灯片均已生成、16:9 安全边距已检查、通用与风格专属质量清单均通过后，才算 route 完成。
