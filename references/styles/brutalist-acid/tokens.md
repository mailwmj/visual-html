# Brutalist Acid (酸性/粗野海报风)

> **设计理念：**
> 灵感来源于 Art Book Fair、酸性设计 (Acid Graphic) 与瑞士朋克排版 (Swiss Punk Typography)。通过破坏性的巨大字号、高饱和度的霓虹荧光色（亮粉与青绿）碰撞、不规则粗野几何色块叠加，以及散点式的排版，构建极具视觉冲击力的先锋艺术展览、独立出版物或实验性设计的页面表现。

## 1. Design Tokens (色彩与变量约定)

*   **色彩体系**:
    *   `--bg`: `#FFFFFF` (纯白背景，作为高对比度的画布)
    *   `--text-main`: `#000000` (正文及小标题绝对纯黑)
    *   `--text-muted`: `#333333`
    *   `--signal-pink`: `#FF4591` (亮粉红/酸性粉，常用于无规则几何背景块)
    *   `--signal-cyan`: `#00E5CC` (荧光青，常用于超大号 Hero 标题，与粉色产生撞色)
*   **字体栈**:
    *   英文字体：`"Helvetica Neue", Helvetica, Arial, sans-serif`
    *   中文字体：`"PingFang SC", "Microsoft YaHei", "微软雅黑", sans-serif`
*   **排版特征**:
    *   超大字号 (Massive Typography)：标题文字极其巨大，甚至超出屏幕，文字常常被当成图形使用。
    *   负字距：紧凑的字距 `letter-spacing: -0.05em`。
    *   无规则底块：使用 CSS `clip-path` 或多重矩形叠加模拟随意拼贴的粉色色块。

## 2. 核心架构覆写契约 (16 个标准组件视觉定义)

为了确保 AI 在生成时完全遵循酸性粗野风格，所有基础组件的视觉呈现约定如下：

1. **Hero (大标题)**: 极度夸张的大字号，负字距，使用荧光青色 (`#00E5CC`)，叠加在荧光粉的锯齿/不规则背景块上，文字允许溢出或强行断行。
2. **Section Eyebrow (区块索引)**: 带有背景反白的等宽字体，像胶带一样贴在页面上。
3. **Typography Scale (正文文本)**: 纯黑 (`#000`) 粗壮的无衬线标题与小字号说明文字形成极端的比例对比（Brutalist Contrast）。
4. **Technical Spec Row (规格参数栏)**: 舍弃常规表格感，采用极其粗黑的边框 (`2px solid #000`) 拼贴，数值部分使用显眼的酸性粉色放大。
5. **Number Cards (编号卡片列)**: 粗黑边框包围，巨大化的背景序号，悬停时带有锐利的纯色投影（`8px 8px 0px #00E5CC`）。强调态卡片直接填满荧光青。
6. **Feature Card (特性卡片)**: 荧光粉色背景填充，保留原始的粗粝感，顶部的标签带有强烈的打字机/代码风格。
7. **Process Steps (流程步骤)**: 左侧步骤数字极其巨大且被挤压（`line-height: 0.8`），粉色，右侧文本以极简纯黑粗线分隔。
8. **Comparison Table (对比矩阵)**: 破坏传统的细腻表格，使用粗黑线条（`3px solid #000`）网格，高亮列使用荧光青色底色填充。
9. **Metadata Footer (技术页脚)**: 散落在底部的打字机风格（Mono 字体）信息，全部大写。
10. **Admonitions (提示框)**: 像街头警告贴纸一样的设计。带有深黑粗边框与显眼的粉/青色硬阴影偏移。
11. **Timeline (时间轴)**: 左侧使用粗黑线，时间节点使用荧光青底黑字的“标签式”打字机设计，不加圆角。
12. **Pros & Cons (红黑榜)**: 舍弃常规的红绿配置，而是使用极具视觉刺激的青色透明底（优势）与粉色透明底（劣势）对抗，标签极具冲击力。
13. **Stats Grid (数据卡片)**: 不使用外边框，而是使用极其粗壮的底部强调线（粉/青交替），数值字号无限放大。
14. **Flowchart (SVG 流程图)**: 节点没有圆角（`rx="0"`），填充绝对纯色（青/粉），连线和边框都是粗壮的 `stroke-width="3"` 黑线，具有强烈的印刷波普感。
15. **References (参考文献)**: 像原始的 HTML 默认样式一样，仅用一条顶部粗线分隔，返璞归真。
16. **Rich Text & FAQ (长文本与问答)**: 引用块（Blockquote）带有极其粗壮的左侧粉色边框，问答列表同样使用原始的粗黑底线分隔。

## 3. 专属质检项 (Checklist)

- [ ] 是否具备了经典的粉青撞色（Hot Pink vs Cyan）？
- [ ] 核心 Hero 标题字号是否足够巨大、具有图形感？
- [ ] 页面中是否运用了不规则块状或几何图形来打破常规阅读视线？
- [ ] 是否保持了正文的小字与标题的巨大字号形成极端的比例对比（Brutalist Contrast）？
