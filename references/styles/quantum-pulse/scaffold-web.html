02 / CONTEXT & CODE

先把证据摆平，再让信号发亮。

CORE RULE / 先保真，再发光

视觉层只能改变信息的路径和焦点，不能删去原文中的限定条件、数据来源和反例。

复杂内容不是一张海报，而是一组可以被复查的关系。Quantum Pulse 用黑色留白降低噪声，用蓝色信号线表达关联，用白色高光承托真正重要的判断。

“光束是导视，不是装饰；网格是证据的坐标系，不是背景纹理。”

三项交付原则

  • 保留上下文：每个数字都带单位、范围与来源。
  • 让关系可追踪：流程、时间线和对比表共享同一蓝色信号语法。
  • 让页面可离线：字体和图表增强失败时，正文与静态 fallback 仍可读。

05 / FAQ & REFERENCES

让每个假设都能回到坐标系。

可以把蓝色曲面放到正文中间吗？

可以，但应作为章节转场或数据焦点，不能让曲面直接压过连续正文。

没有图表时如何保持科技感？

用等宽元数据、细网格、斜向分割线和少量半调媒体框即可，不需要额外装饰。

移动端是否保留斜向光束？

保留一条 1px 低不透明度光束，并缩短切入曲面的高度；正文和表格始终优先。
