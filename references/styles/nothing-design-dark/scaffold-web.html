02 / CONTEXT & NARRATIVE [ DOC // N-02 ]

SYSTEM NOTICE // TELEMETRY RULES [ CORE_RULE ]

多通道色彩原则：色彩不是无意义的装饰，而是精确的遥测状态。珊瑚橙代表交互焦点与核心指标，翡翠绿指示安全与通过，琥珀金标记分类与警示，高对比白承载长文与点阵数码。

在数字产品设计逐渐陷入千篇一律的玻璃拟态与渐变色块的今天，Nothing Design 重新回归工业出版设计的本源：从 Dieter Rams 的十项原则到 Teenage Engineering 的机械旋钮，每一个像素都必须证明其存在的物理意义。

“Monochrome is the canvas. Color is an event, not a default.” —— 黑色是宇宙的底色，色彩是遥测数据的觉醒。
  • Primary 焦点层：Doto 点阵超大数值与重点标题，独占视线焦点。
  • Secondary 正文层：Space Grotesk 高对比排版，保证长文可读性。
  • Tertiary 仪器层：Space Mono 等宽大写元数据，如同精密仪器铭牌。

使用 Space Mono 渲染所有标签、参数与操作按键，确保界面的工程精准感。

// Initialize Nothing Telemetry Engine
pub fn spawn_instrument_deck() -> Result<Deck, Error> {
    let canvas = Canvas::new("OLED_BLACK", DotGrid::Density(24));
    let telemetry = TelemetryChannels {
        coral: SignalColor::from_hex("#FF5722"),

    };
    Ok(Deck::mount(canvas, telemetry))
}

● CORE ADVANTAGES // 优势
  • 极致专注与多维遥测：黑白基底排除噪音，多通道信号色直观呈现负载与健康度。
  • 硬件级辨识度：点阵与分段刻度槽构建强烈数码硬件质感。
  • OLED 极低能耗：纯黑背景在移动端与 OLED 屏幕上达到最高能效比。
● TRADE-OFFS // 约束边界
  • 功能色彩需严格对齐语义：禁止脱离状态定义的任意涂色。
  • 字阶纪律严苛：要求设计者具备极高的排版与字距把控能力。

05 / FAQ & REFERENCES [ INFO // 05 ]

常见问题与系统归档

[ Q1 ] 如何在长文本中合理运用多通道遥测色？
正文长篇段落保持高清晰度黑白灰阶，珊瑚橙用于主焦点与重点指标，翡翠绿用于通过与安全，琥珀金用于分类与告警，色彩仅出现在微小的状态指示灯、分段刻度与图表线上。
[ Q2 ] 如何保证中文在 Nothing 风格下的阅读美感？
字体栈采用 `Space Grotesk` 搭配 `PingFang SC` 与 `HarmonyOS Sans SC`，在大标题处配合负字距收紧，正文保持 1.75 倍行高，兼顾现代瑞士几何感与中文排版的流畅呼吸。
