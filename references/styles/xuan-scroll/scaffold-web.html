02 / NARRATIVE

笔势有秩序，留白有用途

戒

边界条件

不要把推演结果写成事实；来源、口径和不确定性必须留在正文中。

软笔的价值在于变化：笔尖和笔侧、速度和压力、含墨量和收笔方式共同决定线条的性格。界面不需要模拟一团烟雾，而应保留这些关系带来的方向、轻重和停顿。

空处不是缺失的内容，而是让下一段文字获得呼吸的纸面。

三项阅读原则

  • 长正文维持稳定列宽与舒适行距。
  • 墨迹只出现在章节边缘或语义节点。
  • 来源以题跋方式收束，不覆盖正文。

为什么不保留动态水墨烟岚？
结论持续运动会让墨成为主角；本风格只保留落笔瞬间和纸面边缘的变化。
DECISION // 设计拍板
采用半生熟正文纸性，生宣只用于少量标题与引文。
05 / COLOPHON

题跋、问答与出处

可以把所有标题都写成毛笔字吗？
不建议。书法字只承担短标题和视觉锚点，长标题、表格和正文使用可读的宋体或系统衬线字体。
没有真实图片时如何表达纸张？
使用低对比度 CSS 纤维和局部 SVG 笔触；不制造虚假的作品图片，也不把纹理放到文字上方。
