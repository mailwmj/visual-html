02 / PHILOSOPHY & WORKFLOW

双轨制设计哲学与洁净室法则

核心设计约束：洁净室法则 (Clean Room Design)

在基于多模态参考图逆向生成或开发全新风格时，严禁直接继承旧模板中的硬编码样式。必须基于标准纯 HTML 基座独立声明 Design Tokens 与 CSS 规则，从物理上杜绝跨风格样式污染与视觉退化。

Visual HTML 采用三层空间解耦模型（Three-Layer Spatial Architecture）：Layer 0 为环境背景层（Ambient Canvas），承载全屏纹理与情绪张力；Layer 1 为承托画板层（Carrier Board），规范长文流式的视觉边界；Layer 2 为具象组件层（Semantic Components），赋予卡片、列表与表格独特的触感与材质。

“统一的是信息语义能力，具象化的是风格灵魂；杜绝千篇一律的白卡片，拒绝未经推演的粗暴摘要。”

生产级网页交付的三项核心原则

  • 信息全量结构化保真：长文中的核心论据、数据指标与推演脉络必须完整映射至对应组件，严禁 AI 偷懒截断。
  • 多端自适应布局契约：所有网格（Grid）、对比矩阵（Matrix）均内建弹性断点与横向滚动容灾保护，确保移动端无缝浏览。
  • 零外部样式依赖：所有样式规则内联收敛在单个 HTML 文件内，双击即可在任意离线浏览器中完美渲染。

05 / FAQ & REFERENCES

常见问题与规范出处

为什么坚持单文件内联交付（Single-File HTML），而非外链 CSS？
单文件交付保证了极端网络环境下的 100% 可用性与持久归档。无论是通过邮件分发、内部内网查看还是脱机演讲，所有排版、矢量图表与交互均立即可用，避免因外链失效导致页面渲染崩坏。
如何确保生成的页面在移动端和小屏设备上不发生布局溢出？
所有多列网格均配置基于 minmax 的弹性响应断点，表格与对比矩阵均外包带 -webkit-overflow-scrolling: touch 的横向滚动容器，SVG 与 Mermaid 容器均配置 100% 宽度自适应。
