10 / RICH TEXT

长文本正文容器

这是标准的正文段落。在现代排版系统中，为了确保长时间阅读的舒适度，我们对面宽（Measure）、行高（Leading）和字距（Tracking）都进行了严格的打磨。支持 加粗强调、斜体修饰 以及 内联代码 (Inline Code) 等基础排版元素。

当我们面对成千上万字的技术文档或是研究报告时，缺乏层次的长篇大论往往会让人产生阅读疲劳。因此，AI 大脑在提取内容时，不仅仅是把文字按原样输出，而是会像一个经验丰富的编辑一样，自动为关键段落提取核心结论，或者将时间序列转化为可视化的时间轴。

“排版设计的本质不是装饰，而是为了信息的清晰传达而做出的视觉契约。每一处留白，都在引导用户的视线流动。”

排版的四个核心原则

为了达到最佳的跨端阅读体验，我们在这套系统中确立了以下几项不可妥协的设计底线：

  • 可读性至上：深色模式的文本绝不使用纯白（#FFFFFF），避免产生刺眼的光晕效应；浅色模式同样不使用纯黑。
  • 统一的组件契约：无论视觉风格如何切换，底层的语义化组件（如时间轴、对比框）必须保证 100% 的渲染成功率。
  • 中西文混排规范：优雅的字体栈回退机制，确保在 Windows / macOS 系统下都能获得最佳的中英文混排效果，坚决弃用丑陋的宋体。
  • 网格系统的弹性：基于 CSS Grid 与 Flexbox 打造的弹性系统，确保卡片与数据的展示在手机与桌面端都能自适应排布。

这不仅仅是一套前端 CSS 模板，而是将枯燥的长文本结构化、视觉化重构的“中枢神经”。
