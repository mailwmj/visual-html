SYSTEM NOTICE // TELEMETRY RULES [ CORE_RULE ]

多通道色彩原则：色彩不是无意义的装饰，而是精确的遥测状态。信号红代表交互焦点与重点指标，翡翠绿指示安全与通过，琥珀金标记分类与警示，高对比黑承载长文与点阵数码。

在白瓷工业美学的指引下，Nothing Design Light 呈现出如包豪斯印刷品般的极简质感：高对比纯黑字体、1px 浅灰发丝边框与点阵几何相得益彰。

“White is the canvas of light. Structure is the ornament of logic.” —— 白色是光明的基底，结构是逻辑的装饰。
  • Primary 焦点层：Doto 点阵超大数值与重点标题，独占视线焦点。
  • Secondary 正文层：Space Grotesk 高对比排版，保证长文可读性。
  • Tertiary 仪器层：Space Mono 等宽大写元数据，如同精密仪器铭牌。

使用 Space Mono 渲染所有标签、参数与操作按键，确保界面的工程精准感。

// Initialize Nothing Light Telemetry Engine
pub fn spawn_white_deck() -> Result<Deck, Error> {
    let canvas = Canvas::new("CERAMIC_WHITE", DotGrid::Density(24));
    let telemetry = TelemetryChannels {
        red: SignalColor::from_hex("#D71921"),
        green: SignalColor::from_hex("#16A34A"),
        amber: SignalColor::from_hex("#D97706"),
    };
    Ok(Deck::mount(canvas, telemetry))
}

05 / FAQ & REFERENCES [ INFO // 05 ]

常见问题与系统归档

[ Q1 ] Nothing Design Light 与 Dark 版本的区别？
Light 版本以纯粹陶瓷白为底色，深色文字配合信号红与翡翠绿，带来现代包豪斯印刷品的高级质感；Dark 版本则以 OLED 纯黑为底，适合沉浸式仪表盘与夜间阅读。
[ Q2 ] 如何保证中文在 Nothing Light 风格下的阅读美感？
字体栈采用 `Space Grotesk` 搭配 `PingFang SC` 与 `HarmonyOS Sans SC`，在大标题处配合负字距收紧，正文保持 1.75 倍行高，兼顾现代瑞士几何感与中文排版的流畅呼吸。
