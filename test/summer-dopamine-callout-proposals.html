02 / 核心论述与多端自适应体系

Visual HTML 采用三层空间解耦模型（Three-Layer Spatial Architecture）：Layer 0 为环境背景层（Ambient Canvas），承载全屏纹理与情绪张力；Layer 1 为承托画板层（Carrier Board），规范长文流式的视觉边界；Layer 2 为具象组件层（Semantic Components），赋予卡片、列表与表格独特的触感与材质。

INFO / 多巴胺法则 色彩与文字阅读的平衡
背景负责大面积色彩释放，卡片采用白透毛玻璃承托文字，确保长文阅读不刺眼且充满元气。去除生硬的直角粗边框后，组件更加轻盈通透。

在设计多巴胺风格组件时，我们必须保证文字的高对比度和高清晰度，避免由于高饱和色彩喧宾夺主导致用户的阅读疲劳。

TIP / 最佳实践 Pill 胶囊与微光的一致性
全站的所有语义状态（Info、Tip、Warning、Highlight）统一采用一致的 Pill Badge 高度与内微光扩散半径，形成严谨而富有弹性的设计系统。
